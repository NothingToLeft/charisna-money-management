CHARISNA Money Management v12.1.0 — Windows Secure Session
Tanggal: 21 Juli 2026

PERUBAHAN UTAMA
1. Windows menyimpan sesi login Supabase secara terenkripsi memakai Electron safeStorage.
2. Pengguna cukup login email/password satu kali pada komputer tersebut.
3. Menutup aplikasi, masuk tray, restart Windows, dan pembaruan aplikasi tidak memaksa login ulang.
4. Login baru diwajibkan setelah tombol Logout dipilih, sesi dicabut dari server, atau sesi sudah tidak valid.
5. PIN brankas tetap diminta setiap aplikasi dikunci/dibuka agar data keuangan tetap terlindungi.
6. Saat startup Windows ditampilkan layar:
   - Memeriksa pembaruan
   - Memulihkan sesi akun
   - Mengambil cloud terbaru
   - Siap membuka brankas
7. Sesi lama v12 di localStorage dimigrasikan otomatis ke penyimpanan terenkripsi Windows.
8. Android/HP/tablet dan Web/Netlify tidak diubah perilaku loginnya.

KEAMANAN
- Password akun cloud tidak disimpan.
- Yang disimpan adalah token sesi Supabase.
- Token disimpan pada file terenkripsi di folder userData aplikasi Windows.
- Logout menghapus penyimpanan sesi terenkripsi.
- PIN dan kunci dekripsi brankas tidak dibuat permanen oleh fitur ini.
