Kebijakan Privasi

CHARISNA Money Management dirancang sebagai aplikasi local-first. Data keuangan dienkripsi di perangkat sebelum disimpan atau dikirim ke cloud.

Data yang disimpan

Aplikasi dapat menyimpan akun, transaksi, budget, tujuan, utang, investasi, shared wallet, pengaturan, lampiran terenkripsi, dan log teknis. Data lokal berada di penyimpanan browser. Apabila cloud sync aktif, blob terenkripsi disimpan pada proyek Supabase pemilik aplikasi.

Enkripsi

Sandi brankas diproses di browser menggunakan Web Crypto. Server cloud tidak memerlukan isi sandi brankas. Recovery key dapat membuka brankas dan harus disimpan secara rahasia.

Akun cloud

Email dan sesi autentikasi dikelola melalui Supabase Auth. Sandi akun cloud berbeda dari sandi brankas.

Pengingat push

Jika background push diaktifkan, aplikasi menyimpan subscription endpoint dan jadwal pengingat pada Supabase. Mode generik tidak menyertakan nama atau nominal tagihan dalam jadwal push; mode detail menyertakannya agar notifikasi dapat menampilkan informasi tersebut. Pengguna dapat menonaktifkan push dan menghapus subscription perangkat kapan saja.

Layanan pihak ketiga

Aplikasi memuat pustaka dari CDN dan dapat menggunakan Supabase, Netlify, layanan kurs, endpoint bank feed, cloud endpoint, atau webhook yang dikonfigurasi pengguna. Kebijakan masing-masing layanan berlaku pada koneksi tersebut.

Kontrol pengguna

  • Data dapat diekspor sebagai backup terenkripsi.
  • Data lokal dapat dihapus dari menu Setting.
  • Akun cloud dapat dikeluarkan dari perangkat.
  • Pengguna bertanggung jawab menyimpan sandi brankas dan recovery key.

Batasan

Aplikasi ini bukan layanan bank, penasihat investasi, akuntan, atau konsultan pajak. Verifikasi laporan sebelum digunakan untuk keputusan penting.
