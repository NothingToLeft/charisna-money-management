v14.1.2

UI Polish, SuperApp Sync, Universal Modals & CI Hardening

13 November 2026
  • Penyelarasan UI: Palette warna selaras (#4f46e5 indigo, #ec4899 pink cerah), radius kartu lebih lembut (14px-18px), dan font responsif.
  • Modal Input Universal: Menggantikan window.prompt() dengan modal in-app native (showPromptModal) sehingga aman 100% di Electron Windows, Android Capacitor, dan Web PWA tanpa resiko crash.
  • SuperApp Ecosystem Sync: Integrasi event bus dan sinkronisasi data antar modul CHARISNA SuperApp, Bumi Makmur POS, dan CHARISNA Homestay.
  • Keamanan Kunci Sesi: Reset session passkey instan saat aplikasi dikunci, timeout 4 detik pada webhook eksternal via AbortController.
  • Hardening Android & Windows: AndroidManifest backup protection, notifikasi Android 13+, build tool setup-android@v4, dan standarisasi rilis v14.1.2.
  • Platform Integrity: Skrip sinkronisasi otomatis menjaga konsistensi 100% antara Web PWA, Android www, dan Windows Electron app.
Kompatibilitas:

100% kompatibel dengan brankas v6-v14.1. Tidak mengubah skema database atau memerlukan migrasi paksa.

v11.1

Stability & Input Fix

18 Juli 2026
  • Memperbaiki bug kritis nominal yang berhenti pada 1.000; angka kini dapat terus diketik hingga jutaan, miliaran, dan triliunan.
  • Formatter mendukung desimal koma, tombol titik pada numpad, paste format Indonesia/Inggris, angka negatif, backspace pada separator, serta pengeditan posisi kursor.
  • Kolom kosong tidak lagi berubah sendiri menjadi 0 dan validasi minimal/maksimal tetap bekerja walaupun tampilan memakai pemisah ribuan.
  • Nilai yang diisi dari template transaksi kini langsung memperbarui formatter, autocomplete, saran kategori, dan pemeriksaan duplikat.
  • Memperbaiki refresh nilai kurs manual yang sebelumnya dapat salah membaca 1.000 sebagai 1.
  • Menambahkan navigasi keyboard pada autocomplete dengan panah atas/bawah dan Enter.
  • Memperbaiki kategori lama/legacy agar tetap muncul saat transaksi diedit dan referensi kategori induk ikut berpindah saat rename/merge.
  • Memperbaiki tampilan kurs kosong agar menampilkan tanda —, bukan angka 0 yang menyesatkan.
  • Menambahkan validasi input terpusat dan audit statis paket.
