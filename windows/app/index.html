Brankas terenkripsi tersinkron melalui akun Supabase.

Memeriksa akun cloud...

Menunggu status sinkronisasi.

Autosave berjalan setiap ada perubahan, sebelum lock/logout, dan ketika koneksi kembali. Versi cloud terbaru selalu dipakai otomatis; salinan lokal sebelumnya disimpan sebagai recovery terenkripsi.

Bank Feed / Open Banking Adapter

Endpoint harus mengembalikan array transaksi dalam format JSON.

Webhook & API

Kirim snapshot terenkripsi setelah perubahan data.

Zona Berbahaya

Penghapusan tidak dapat dibatalkan tanpa backup.
